# Έφτιαξα έναν live editor για να αλλάζω τη σελίδα όπως τη βλέπω

Ένα πείραμα οπτικής επεξεργασίας που φέρνει την αλλαγή περιεχομένου πιο κοντά στο τελικό αποτέλεσμα.

Βλέπεις μια παράγραφο στη σελίδα και σκέφτεσαι ότι θα μπορούσε να είναι καλύτερη. Το πιο φυσικό θα ήταν να την αλλάξεις εκεί, μέσα στο περιβάλλον όπου τη διαβάζεις.

Αυτή την εμπειρία εξερευνά το Content 4. Ένα δικό μου κομμάτι ενσωμάτωσης για live editing, που αξιοποιεί τον οπτικό editor Froala και συνδέει τις αλλαγές με την ιστοσελίδα.

## Η αλλαγή μέσα στο περιβάλλον της

Ένα κείμενο φαίνεται διαφορετικό όταν το βλέπεις μόνο του σε μια φόρμα και διαφορετικό όταν βρίσκεται δίπλα στις υπόλοιπες ενότητες. Η ζωντανή επεξεργασία κρατά αυτό το πλαίσιο μπροστά σου.

Μπορείς να δουλέψεις μια ανακοίνωση, να αλλάξεις τη διατύπωση μιας παραγράφου και να δεις τη σχέση της με το υπόλοιπο περιεχόμενο. Η εμπειρία γίνεται περισσότερο οπτική και άμεση.

## Οι παρεμβάσεις έχουν τη δική τους θέση

Η κατασκευή κρατά τις αλλαγές χωριστά από την αρχική σελίδα και τις εφαρμόζει όταν αυτή εμφανίζεται. Υπάρχουν παρεμβάσεις για μια συγκεκριμένη σελίδα και παρεμβάσεις που μπορούν να χρησιμοποιηθούν συνολικά.

Αυτή η ιδέα αφήνει χώρο για πειραματισμό και επαναφορά. Το αρχικό template παραμένει η βάση πάνω στην οποία δουλεύεις.

Το Content 4 είναι ένα μικρό εργαστήριο για κάτι που μοιάζει αυτονόητο όταν το χρησιμοποιείς: να μπορείς να διορθώσεις αυτό που βλέπεις. Η σύνδεση αυτής της εμπειρίας με μια υπάρχουσα PHP σελίδα είναι το ενδιαφέρον μέρος του project.
