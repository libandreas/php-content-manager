# Έφτιαξα ένα δικό μου CMS, με τον δικό μου τρόπο

Ένα χειροποίητο project για να αποκτούν οι ιστοσελίδες περισσότερη ελευθερία και λιγότερη καθημερινή ταλαιπωρία.

Μια ιστοσελίδα μπορεί να είναι ακριβώς όπως την έχεις φανταστεί. Έχεις διαλέξει πού θα μπει κάθε κείμενο, πώς θα εμφανίζονται οι σελίδες και τι θα βλέπει ο επισκέπτης. Μετά έρχεται η πρώτη μικρή αλλαγή. Και η δεύτερη. Και ξαφνικά, για δύο προτάσεις, βρίσκεσαι πάλι μέσα στον κώδικα.

Αυτό είναι το πρόβλημα γύρω από το οποίο περιστρέφεται το δικό μου CMS. Ένα περιβάλλον διαχείρισης που δίνει στις χειροποίητες σελίδες τη δυνατότητα να αλλάζουν πιο εύκολα.

## Η χαρά τού να το φτιάχνεις μόνος σου

Το project συνδυάζει διαχείριση σελίδων, άρθρων και χρηστών. Το περιεχόμενο αποθηκεύεται σε αρχεία και η PHP ενώνει τα κομμάτια. Είναι μια κατασκευή που μπορείς να ανοίξεις, να εξερευνήσεις και να προσαρμόσεις στα μέτρα σου.

Το ωραίο είναι ότι ο σχεδιασμός της ιστοσελίδας παραμένει δικός σου. Το CMS έρχεται να προσθέσει δυνατότητες επεξεργασίας γύρω από αυτόν. Μπορείς να φανταστείς μια μικρή προσωπική σελίδα, ένα blog ή μια συλλογή καταχωρίσεων να αποκτούν το δικό τους κέντρο ελέγχου.

## Μια συλλογή από δικές μου ιδέες

Μέσα στο ίδιο project συναντιούνται διαφορετικά πειράματα: αλλαγές κειμένων από το panel, οπτική επεξεργασία πάνω στη σελίδα και οργάνωση περιεχομένου χωρίς βάση δεδομένων.

Αυτό που θέλω να φαίνεται είναι η διάθεση για κατασκευή. Να παίρνεις κάτι που χρησιμοποιείς καθημερινά, να αναρωτιέσαι πώς θα το έκανες εσύ και να του δίνεις τη δική σου μορφή. Ένα μικρό CMS μπορεί να γίνει πολύ ενδιαφέρον προσωπικό εργαστήριο!
