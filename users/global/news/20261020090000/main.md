# Έφτιαξα ένα CMS για τις ιστοσελίδες που ήδη είχα

Η ιδέα ενός πρόσθετου panel που δίνει νέα ζωή σε υπάρχουσες PHP σελίδες, χωρίς να ξεκινάς τον σχεδιασμό από την αρχή.

Μια ιστοσελίδα μπορεί να είναι έτοιμη και να δείχνει ακριβώς όπως τη θέλεις. Μέχρι να χρειαστεί να αλλάξεις δύο προτάσεις και να ξανανοίξεις τον κώδικα. Από εκεί ξεκινά η ιδέα αυτού του project: ένα μικρό, δικό μου περιβάλλον διαχείρισης που προστίθεται στις σελίδες και τις κάνει επεξεργάσιμες.

Το ωραίο είναι η ελευθερία που δίνει. Κρατάς τον σχεδιασμό σου, τη δομή σου και τον τρόπο που έχεις χτίσει την ιστοσελίδα. Προσθέτεις τη δυνατότητα να αλλάζεις τίτλους, κείμενα και περιεχόμενο από ένα panel. Μια χειροποίητη σελίδα αποκτά έτσι ένα χειροποίητο CMS!

## Μια παλιά σελίδα μπορεί να έχει συνέχεια

Φαντάσου μια μικρή σελίδα παρουσίασης ενός project. Αρχικά έχει λίγα κείμενα και μερικές ενότητες. Αργότερα χρειάζεται νέα περιγραφή, περισσότερες πληροφορίες και ίσως ένα blog για τις ενημερώσεις του.

Αυτό είναι ένα ενδεικτικό σενάριο για το οποίο έχει ενδιαφέρον η συγκεκριμένη προσέγγιση. Οι δυνατότητες μπορούν να προστεθούν γύρω από την υπάρχουσα δουλειά, ανάλογα με το τι χρειάζεται η εφαρμογή.

## Το προσωπικό εργαστήριο μεγαλώνει

Η συλλογή καλύπτει άρθρα, χρήστες, επεξεργασία σελίδων και ζωντανές αλλαγές. Κάθε κομμάτι προσφέρει έναν ακόμη τρόπο να αξιοποιήσεις το site που χτίζεις.

Το πιο ενδιαφέρον για μένα είναι αυτή η αίσθηση συνέχειας: μια ιστοσελίδα μπορεί να εξελίσσεται μαζί με τις ιδέες σου. Και ένα προσωπικό PHP project μπορεί να της δώσει τα εργαλεία για να το κάνει.
