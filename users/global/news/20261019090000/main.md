# Έδωσα στις HTML σελίδες μου το δικό τους panel

Μια χειροποίητη σελίδα αποκτά τη δυνατότητα να αλλάζει περιεχόμενο εύκολα, κρατώντας τον χαρακτήρα της.

Έχεις φτιάξει μια σελίδα με τα χέρια σου και σου αρέσει όπως είναι. Το επόμενο που θέλεις είναι να μπορείς να αλλάξεις την περιγραφή, μια ανακοίνωση ή τον τίτλο της χωρίς κάθε φορά να επιστρέφεις στον editor κώδικα.

Εδώ μπαίνει το Content 3. Η ιδέα του είναι να δώσει σε υπάρχουσες σελίδες ένα δικό τους περιβάλλον επεξεργασίας.

## Η σελίδα παραμένει δική σου

Το panel αναλαμβάνει τα κείμενα και τις περιοχές περιεχομένου που έχουν επιλεγεί. Μπορείς να ανανεώσεις την παρουσίαση ενός project ή να ξαναγράψεις μια ενότητα, κρατώντας τη δομή που ήδη έχεις σχεδιάσει.

Αυτό έχει μια ωραία πρακτική πλευρά. Η δουλειά που έκανες για την εμφάνιση της σελίδας συνεχίζει να αξιοποιείται και η καθημερινή ενημέρωση γίνεται πιο άμεση.

## Ένα μικρό εργαλείο που ανοίγει δυνατότητες

Σκέψου μια προσωπική ιστοσελίδα με μερικές σελίδες έργων. Κάθε project αλλάζει, αποκτά νέες λειτουργίες και χρειάζεται καλύτερη περιγραφή. Ένα τέτοιο panel δίνει χώρο σε αυτές τις αλλαγές χωρίς να μετατρέπει κάθε ενημέρωση σε δουλειά προγραμματισμού.

Η κατασκευή μπορεί να συνυπάρχει και με δυναμικές σελίδες PHP. Έτσι το περιεχόμενο και οι λειτουργίες της εφαρμογής συνεχίζουν να μοιράζονται την ίδια σελίδα.

Το Content 3 είναι ένα από εκείνα τα DIY εργαλεία που έχουν ξεκάθαρο σκοπό: να κάνουν πιο εύχρηστο κάτι που έχεις ήδη φτιάξει. Και αυτό είναι αρκετά καλός λόγος για να το κατασκευάσεις.
