# PHP Content Manager

Το PHP Content Manager είναι ένα σύστημα διαχείρισης περιεχομένου που προσθέτει εργαλεία επεξεργασίας σε υπάρχουσες ιστοσελίδες PHP. Περιλαμβάνει διαχείριση άρθρων, επεξεργασία σελίδων, live editor, μεταφράσεις, λογαριασμούς χρηστών και καταχωρίσεις, με αποθήκευση σε αρχεία JSON, Markdown και αρχεία της ιστοσελίδας.

Η βασική ιδέα είναι να μπορεί μια ιστοσελίδα να αποκτήσει περιβάλλον διαχείρισης διατηρώντας τον δικό της σχεδιασμό. Ο προγραμματιστής επιλέγει τις λειτουργίες που χρειάζεται και τις συνδέει με την εφαρμογή του.

Το project αποτελεί δείγμα της δουλειάς μου πάνω σε εργαλεία PHP για διαχείριση ιστοσελίδων και περιεχομένου.

## Σκοπός του project

Μια χειροποίητη ιστοσελίδα χρειάζεται συχνά αλλαγές μετά την αρχική της κατασκευή: νέα κείμενα, άρθρα, εικόνες, μεταφράσεις και ενημερώσεις στοιχείων.

Το Content Manager συγκεντρώνει αυτές τις εργασίες σε επιμέρους εργαλεία διαχείρισης. Άλλες αλλαγές αποθηκεύονται απευθείας στα αρχεία της σελίδας και άλλες εφαρμόζονται στο HTML κατά την εμφάνισή της.

Η προσέγγιση επιτρέπει την προσθήκη λειτουργιών σε διαφορετικές εφαρμογές PHP. Ο κώδικας περιλαμβάνει επίσης σημεία ενσωμάτωσης με WordPress, τα οποία χρειάζονται προσαρμογή στην εκάστοτε εγκατάσταση.

## Βασικές δυνατότητες

- Δημιουργία και επεξεργασία άρθρων με αποθήκευση σε Markdown.
- Επεξεργασία επιλεγμένων περιοχών HTML από το περιβάλλον διαχείρισης.
- Οπτική επεξεργασία περιεχομένου πάνω στη σελίδα.
- Εφαρμογή μεταφράσεων από αρχείο JSON.
- Λογαριασμοί χρηστών, προφίλ και προσωπικές καταχωρίσεις.
- Επεξεργασία πηγαίου κώδικα μέσω Monaco Editor.
- Αντιστοίχιση διευθύνσεων και ανακατευθύνσεις μέσω CSV.
- Συνοδευτικά εργαλεία email, επαλήθευσης φορμών και διαγνωστικών.

## Πώς λειτουργεί

Το σύστημα συνδέεται με τη σελίδα μέσω των αντίστοιχων αρχείων PHP στον φάκελο `common/`.

Ανάλογα με τη λειτουργία, το εργαλείο:

1. Διαβάζει τα δεδομένα της εφαρμογής ή το περιεχόμενο της σελίδας.
2. Εμφανίζει τις διαθέσιμες επιλογές διαχείρισης στον κατάλληλο χρήστη.
3. Αποθηκεύει τις αλλαγές στην αντίστοιχη μορφή αρχείου.
4. Χρησιμοποιεί τα ενημερωμένα δεδομένα στην επόμενη εμφάνιση της σελίδας.

Ορισμένες λειτουργίες χρησιμοποιούν το output buffering της PHP: επεξεργάζονται το παραγόμενο HTML πριν αυτό σταλεί στον browser. Έτσι εφαρμόζονται αλλαγές και προστίθενται εργαλεία διαχείρισης στην έξοδο της ιστοσελίδας.

## Τρεις τρόποι διαχείρισης περιεχομένου

Το σύστημα περιλαμβάνει τρεις διαφορετικές προσεγγίσεις, καθεμία για διαφορετική ανάγκη.

| Λειτουργία | Χρήση | Αποθήκευση |
| --- | --- | --- |
| **Content 2** | Άρθρα, ειδήσεις και περιεχόμενο ιστολογίου | Markdown και συνοδευτικά αρχεία πεδίων |
| **Content 3** | Επεξεργασία συγκεκριμένων περιοχών μιας σελίδας | Στο αρχείο HTML ή PHP της σελίδας |
| **Content 4** | Οπτικές αλλαγές πάνω στην εμφανιζόμενη σελίδα | Στο `live-edits.json` |

### Content 2: άρθρα και ιστολόγιο

Το `content-2.php` παρέχει λειτουργίες δημιουργίας και επεξεργασίας άρθρων, εικόνων και κατηγοριών.

Κάθε άρθρο αποθηκεύεται σε δικό του φάκελο. Το `main.md` περιέχει τον τίτλο και το περιεχόμενο, ενώ πρόσθετα αρχεία μπορούν να κρατούν στοιχεία όπως η περίληψη.

```text
users/
  global/
    news/
      20261017090000/
        main.md
        description.txt
```

Η παρουσίαση παραμένει στο template της ιστοσελίδας. Το ίδιο αποθηκευμένο άρθρο μπορεί να χρησιμοποιηθεί σε λίστα ειδήσεων και σε ξεχωριστή σελίδα ανάγνωσης.

Το `demo-news.php` δείχνει μια λίστα πέντε ελληνικών άρθρων με σελιδοποίηση. Το `demo-news-template.php` λειτουργεί ως κοινό template για την προβολή τους.

### Content 3: επεξεργασία περιοχών σελίδας

Το `content-3.php` επιτρέπει την επεξεργασία περιεχομένου που βρίσκεται ήδη μέσα σε μια σελίδα.

Ο προγραμματιστής ορίζει τις επεξεργάσιμες περιοχές με κλάσεις όπως `html`, `html-*` και `text-*`. Ο διαχειριστής μπορεί στη συνέχεια να ενημερώνει αυτές τις περιοχές από το panel.

Παράδειγμα:

```php
<?php
require_once __DIR__ . '/common/content-3.php';
?>
<!DOCTYPE html>
<html lang="el">
<head>
    <meta charset="UTF-8">
    <title>Η σελίδα μου</title>
</head>
<body>
    <section class="html">
        <h1>Η παρουσίασή μας</h1>
        <p>Περιεχόμενο που μπορεί να ενημερωθεί από το panel.</p>
    </section>

    <p class="text-contact">Στοιχεία επικοινωνίας</p>
</body>
</html>
```

Οι αλλαγές αποθηκεύονται στο αρχείο της σελίδας. Για αυτό χρειάζονται δικαιώματα εγγραφής στα αρχεία που θα επεξεργάζεται το σύστημα.

### Content 4: live editor

Το `content-4.php` προσφέρει οπτική επεξεργασία πάνω στην ίδια τη σελίδα.

Οι αλλαγές αποθηκεύονται στο `live-edits.json` και εφαρμόζονται στο παραγόμενο HTML. Μπορούν να αφορούν συγκεκριμένη διεύθυνση ή κοινές αλλαγές, ανάλογα με τον τρόπο αποθήκευσής τους.

Το αρχικό αρχείο της σελίδας παραμένει η βάση της παρουσίασης. Το JSON κρατά τις πρόσθετες αλλαγές που εφαρμόζονται κατά την εμφάνιση.

Ο live editor χρησιμοποιεί τον εξωτερικό Froala Editor μέσω CDN, με τους αντίστοιχους όρους χρήσης του.

## PHP Translate Plugin

Τα `translate-site.php` και `translate-site.js` παρέχουν μηχανισμό εφαρμογής μεταφράσεων από το `live-translates.json`.

Η PHP επεξεργάζεται το HTML της σελίδας, ενώ το JavaScript υποστηρίζει την εφαρμογή μεταφράσεων σε περιεχόμενο που προστίθεται δυναμικά.

Το σύστημα χρησιμοποιεί αποθηκευμένες αντιστοιχίσεις κειμένων. Η συγκεκριμένη λειτουργία δεν αποτελεί από μόνη της υπηρεσία αυτόματης παραγωγής μεταφράσεων.

Το `demo-page-3.php` παρουσιάζει το εργαλείο σε μια σελίδα που υποστηρίζει και επεξεργασία περιεχομένου μέσω Content 3.

## Χρήστες, προφίλ και καταχωρίσεις

Το `users.php` παρέχει λειτουργίες λογαριασμών και διαχείρισης δεδομένων χρηστών με αποθήκευση στο `users.json`.

Τα παραδείγματα του project δείχνουν μια πλήρη διαδρομή χρήσης:

| Σελίδα | Λειτουργία |
| --- | --- |
| `register.php` | Δημιουργία λογαριασμού |
| `login.php` | Σύνδεση χρήστη |
| `profile.php` | Προβολή προφίλ |
| `edit-profile.php` | Επεξεργασία προφίλ |
| `list.php` | Προβολή καταχωρίσεων |
| `edit.php` | Προσθήκη ή ενημέρωση καταχώρισης του χρήστη |

Οι καταχωρίσεις του demo περιλαμβάνουν πεδία όπως τίτλος, περιγραφή, τιμή, κατηγορία και τοποθεσία.

Για τη διαχείριση του CMS χρησιμοποιούνται επίσης τα `content-0.php` και `content-1.php`, που καλύπτουν σύνδεση και διαχείριση σχετικών στοιχείων.

## Επεξεργασία κώδικα

Τα `content-8.php` και `content-8.js` παρέχουν επεξεργασία αρχείων PHP, HTML, CSS και JavaScript μέσω Monaco Editor.

Η λειτουργία προορίζεται για εργασίες πάνω στον πηγαίο κώδικα από το περιβάλλον διαχείρισης. Είναι ξεχωριστή από την επεξεργασία περιεχομένου των Content 2, 3 και 4.

## Εκτέλεση των παραδειγμάτων

Εγκαταστήστε τις βιβλιοθήκες PHP από τη ρίζα του project:

```bash
composer install
```

Το `composer.json` περιλαμβάνει:

- **Parsedown** για ανάγνωση Markdown.
- **HTML to Markdown** για μετατροπή περιεχομένου.
- **PHPMailer** για αποστολή email.

Στη συνέχεια:

1. Ορίστε τη ρίζα του project ως document root σε web server με PHP.
2. Δώστε δικαιώματα εγγραφής στα αρχεία και στους φακέλους δεδομένων που χρησιμοποιούν οι επιλεγμένες λειτουργίες.
3. Ανοίξτε το `/demo-news.php` για τα παραδείγματα άρθρων.
4. Χρησιμοποιήστε τις σελίδες demo για να δείτε τους διαφορετικούς τρόπους επεξεργασίας.

| Παράδειγμα | Τι παρουσιάζει |
| --- | --- |
| `demo-news.php` | Λίστα άρθρων με σελιδοποίηση |
| `demo-news-template.php` | Κοινό template άρθρου |
| `demo-page-1.php` | Σελίδα παρουσίασης του CMS με αρχεία |
| `demo-page-2.php` | Επεξεργάσιμες περιοχές HTML μέσω Content 3 |
| `demo-page-3.php` | Παρουσίαση του μηχανισμού μεταφράσεων |
| `demo-page-4.php` | Live editing μέσω Content 4 |

Η πρόσβαση στις επιλογές διαχείρισης απαιτεί λογαριασμό με τα κατάλληλα δικαιώματα. Ο απλός λογαριασμός demo των παραδειγμάτων χρηστών δεν υποκαθιστά τον λογαριασμό διαχειριστή.

### Στοιχεία του demo

Για τα παραδείγματα χρηστών παρέχεται ο λογαριασμός:

```text
Username: demo
Password: demo1234
```

Περιλαμβάνει ενδεικτικό προφίλ και τρεις καταχωρίσεις.

Η υπάρχουσα υλοποίηση αποθηκεύει κωδικούς στο JSON χωρίς hashing. Τα παραδείγματα προορίζονται για τοπική εξερεύνηση με δοκιμαστικά στοιχεία. Η αξιοποίηση σε πραγματική εγκατάσταση απαιτεί προσαρμογή της διαχείρισης κωδικών και προστασία των αρχείων δεδομένων από απευθείας πρόσβαση μέσω web.

## Συνοδευτικά εργαλεία

| Εργαλείο | Χρήση |
| --- | --- |
| `url-rewrites.php` | Αντιστοίχιση διευθύνσεων και ενημέρωση συνδέσμων στο HTML |
| `url-redirects.php` | Ανακατευθύνσεις βάσει αρχείου CSV |
| `send.php` | Αποστολή email με τις ρυθμίσεις της εγκατάστασης |
| `recaptcha-v2.php` | Επαλήθευση φορμών μέσω Google reCAPTCHA |
| `errors-handler.*`, `errors-reporting.*` | Εμφάνιση και αναφορά διαγνωστικών μηνυμάτων |
| `errors-cleaner.php` | Καθαρισμός αρχείων `error_log` |
| `auto-init-quill.js` | Σύνδεση πεδίων κειμένου με Quill |
| `input-fixes.js` | Καθαρισμός περιττών κενών σε πεδία φόρμας |
| `responsive.css` | Βοηθητικές κλάσεις εμφάνισης για διαφορετικές οθόνες |
| `polyfills.php`, `polyfills-for-php-8.php` | Συνοδευτικές λειτουργίες συμβατότητας |

Οι λειτουργίες email και reCAPTCHA χρειάζονται τις αντίστοιχες ρυθμίσεις υπηρεσιών. Οι εξωτερικοί editors διατηρούν τις δικές τους εξαρτήσεις και όρους χρήσης.

## Ενσωμάτωση σε υπάρχουσα ιστοσελίδα

Η ενσωμάτωση ξεκινά από την επιλογή της λειτουργίας που χρειάζεται η εφαρμογή.

Για ένα ιστολόγιο χρησιμοποιείται το Content 2 με το template των άρθρων. Για συγκεκριμένες επεξεργάσιμες περιοχές χρησιμοποιείται το Content 3. Για οπτικές αλλαγές που αποθηκεύονται χωριστά από το αρχείο της σελίδας χρησιμοποιείται το Content 4.

Τα αρχεία αρχικοποίησης φορτώνονται πριν από το HTML. Οι διαδρομές, τα δικαιώματα χρηστών και οι θέσεις αποθήκευσης προσαρμόζονται στην εγκατάσταση.

Τα demo λειτουργούν ως παραδείγματα σύνδεσης των εργαλείων με απλές σελίδες PHP και HTML.

## Τι παρουσιάζει ως project

Το PHP Content Manager δείχνει διαφορετικές προσεγγίσεις στο ίδιο πρακτικό πρόβλημα: πώς αποκτά μια ιστοσελίδα δυνατότητα διαχείρισης μετά την κατασκευή της.

Συνδυάζει αποθήκευση σε αρχεία, επεξεργασία HTML, διαχείριση χρηστών, templates άρθρων, οπτικούς editors και συνεργασία PHP με JavaScript.

Ως δείγμα δουλειάς, παρουσιάζει τόσο τη δημιουργία επιμέρους εργαλείων όσο και τη σύνδεσή τους με την καθημερινή διαχείριση μιας ιστοσελίδας.
